Project Overview


Pandas Analyzer & Data Visualization is a beginner-friendly Python project for analyzing sales data and creating charts. It uses Pandas for data handling, NumPy for array operations, Matplotlib for charts, and Seaborn for enhanced visualizations. The project is developed in Jupyter Notebook with a menu-driven interface.
Objectives

Load and analyze sales data from a CSV file.

Explore rows, columns, data types, and dataset information.

Clean missing values and remove duplicate records.

Perform NumPy array and mathematical operations.

Combine and split DataFrames.

Search, sort, and filter records.

Calculate aggregate and statistical values.

Create pivot tables and use GroupBy and Transform.

Create visualizations with Matplotlib and Seaborn.

Save charts and export analysis results.

Dataset

The notebook creates a sample sales dataset automatically in Cell 3 and saves it as sales_data.csv.
Dataset columns: - SalesID - Date - Product - Category - Region - Sales - Profit - Quantity - Year
To use another CSV file, select Load Dataset from the main menu and enter its file path.
How to Run
Open the project notebook in VS Code.
Select a Python Jupyter kernel.
Run the cells one by one in order, from Cell 1 to Cell 7.
Cell 3 creates the sample CSV dataset.
Cell 4 defines the SalesDataAnalyzer class.
Cells 5 and 6 create the object and load the dataset.
Cell 7 starts the main menu.
Enter a menu number to choose an operation.
Important: Run the cells in order. Do not run Cell 7 before the earlier cells.
